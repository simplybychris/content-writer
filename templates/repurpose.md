# 🔄 REPURPOSING PLAYBOOK

Kompletny przewodnik po przekształcaniu contentu między platformami.

---

## 📊 REPURPOSING MATRIX

### Źródło: BLOG POST (1500-2500 słów) → Wszystkie Platformy

#### Blog → LinkedIn (3-5 postów)
1. **Post 1:** Hook + główny problem (intro sekcja)
2. **Post 2:** Case study z konkretnymi wynikami (tabela rezultatów)
3. **Post 3:** Top 3 lekcje (lessons learned)
4. **Post 4:** Tutorial w punktach (skrócony krok po kroku)
5. **Post 5:** FAQ jako Q&A post

#### Blog → Twitter/X (5-7 threadów)
1. **Thread 1:** Statystyki i dane (hook dla liczb)
2. **Thread 2:** Tutorial krok po kroku (każdy krok = tweet)
3. **Thread 3:** Narzędzia i tech stack
4. **Thread 4:** Błędy do uniknięcia (anti-pattern)
5. **Thread 5:** Before/After transformation
6. **Thread 6:** Q&A z komentarzy
7. **Thread 7:** Quick wins (3 najłatwiejsze rzeczy do wdrożenia)

#### Blog → Instagram (10 postów)
1. **Karuzela 1:** Before/After (slide 1 vs slide 2)
2. **Reel:** 30-60 sekund - główny hack + music
3. **Story series:** Behind the scenes (5-7 stories)
4. **Single post:** Cytat z głównym insightem + design
5. **IGTV/Reel:** 3-5 minut tutorial
6. **Karuzela 2:** Checklist (każdy punkt = slide)
7. **Reel:** Reakcja na najczęstsze pytania
8. **Story:** Interactive Q&A z stickerami
9. **Single:** Infografika z danymi/metrykami
10. **Karuzela 3:** Step-by-step guide (każdy krok = slide)

#### Blog → Newsletter (3-częściowa seria)
1. **Email 1:** Problem + teaser rozwiązania + personal story
2. **Email 2:** Case study + social proof + metryki
3. **Email 3:** Tutorial + resources + CTA na konsultację

#### Blog → YouTube
1. **Long-form (10-15 min):** Pełny deep dive z screen share
2. **Short (60s):** Główny hook + najważniejszy insight
3. **Short (60s):** Before/After visualization
4. **Community post:** Ankieta o doświadczeniach widzów

## 🐦 Źródło: TWITTER THREAD → Wszystkie Platformy

### Thread → LinkedIn
**Transformacja:**
- Każdy tweet → osobny paragraf
- Usuń numerację (1/, 2/, 3/)
- Dodaj kontekst biznesowy i profesjonalny ton
- Rozwiń punkty (tweet 280 znaków → paragraf 400 znaków)
- Zakończ pytaniem do społeczności

**Przykład:**
```
Tweet: "1/ Claude dla content creation. Nie piszesz od zera."

LinkedIn: "Odkryłem, że Claude Code rewolucjonizuje content creation. Zamiast patrzeć na pustą stronę, zaczynam od kontekstu i pozwalam AI rozwinąć pomysł. To nie jest pisanie 'od zera' - to praca z inteligentnym partnerem, który rozumie Twój styl i cel."
```

### Thread → Instagram
- Każdy punkt threadu = osobny slide w karuzeli
- Slide 1: Hook z threadu jako cover
- Dodaj wizualizacje (ikony, ilustracje, gradients)
- Story "behind the tweet" - dlaczego ten temat?
- Reel: Główne 3 punkty z voice over

### Thread → Blog Post
**Struktura:**
- **Intro:** Dlaczego ten temat jest ważny (200-300 słów)
- **Każdy punkt threadu = H2** z 3-4 paragrafami rozwinięcia
- Dodaj case studies i konkretne przykłady
- Screenshots/obrazy co 300-400 słów
- FAQ na końcu (pytania z odpowiedzi na thread)

### Instagram → Twitter Thread
- Pierwsza linijka = tweet 1 (hook)

- Dodaj szczegóły i przykłady
- Payoff tweet z głównym insightem

### Instagram → Blog
- Mini-story jako intro
- Value bombs jako H2 sections
- Rozwiń każdy punkt w 400-600 słów
- Dodaj tutorial/how-to

## 💡 PRO TIPS

### Tip #1: Platform Personality Switch
Ten sam content, ale:
- **LinkedIn** = Professional Storyteller
- **Twitter** = Spicy Hot Takes
- **Instagram** = Friend giving advice
- **Blog** = Thoughtful Expert
- **Newsletter** = Trusted mentor

### Tip #2: Content Recycling Timeline
- LinkedIn post → Repost po 3 miesiącach z updatem
- Twitter thread → Repost po 6 tygodniach
- Instagram → Repost po 2 miesiącach (inny czas dnia)
- Blog → Update co 6 miesięcy (dodaj nowe case studies)

### Tip #3: Format Migration
- Text post → Carousel → Video → Infographic
- Ten sam content, 4 różne formaty
- Algorytm traktuje jako nowy content

### Tip #4: Seasonal Repurposing
Ten sam temat z różnym kątem:
- Q1: "Jak zacząć rok z AI"
- Q2: "Mid-year AI optimization"
- Q3: "Preparing for Q4 with AI"
- Q4: "AI wins 2024 + plan na 2025"

## 📅 REPURPOSING WORKFLOW

### Krok 1: Stwórz Pillar Content
Blog post 2000 słów jako źródło prawdy.

### Krok 2: Extract Core Elements
- 1 główny hook
- 3-5 value points
- 1 case study
- 5-10 data points/statystyk
- 3 main takeaways

### Krok 3: Repurpose według Matrix
Użyj powyższych transformacji.

### Krok 4: Schedule & Publish
- LinkedIn: 2x tydzień (wtorek, czwartek 9-11)
- Twitter: 1x dziennie + thread 1x tydzień
- Instagram: 3-5x tydzień
- Blog: 1x tydzień
- Newsletter: 1x tydzień

### Krok 5: Monitor & Iterate
Co działa? Podwoj to. Co nie? Testuj inne podejście.
