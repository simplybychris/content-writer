# 🔄 Content Repurposing System

System do przekształcania jednego contentu w dziesiątki postów na różnych platformach.

## 🚀 Quick Start

1. **Wypełnij `person.md`** - Twój brand, ton, grupa docelowa
2. **Dodaj pomysł do `ideas/content_bank.md`**
3. **Użyj szablonów z `templates/`** do tworzenia contentu
4. **Zaplanuj w `calendar/current_plan.md`**

## 📁 Struktura

```
/content-writer/
├── person.md              # Profil brandu i styl komunikacji
├── templates/             # Szablony dla każdej platformy
│   ├── linkedin.md        # Storytelling (Hook-Story-Value-CTA)
│   ├── twitter.md         # Threads (Hook-Chain-Payoff)
│   ├── instagram.md       # Visual storytelling
│   ├── blog.md           # Long-form (Problem-Solution-Transformation)
│   └── repurpose.md      # Matryca przekształceń między platformami
├── ideas/
│   └── content_bank.md   # Bank pomysłów do repurposingu
└── calendar/
    └── current_plan.md   # Miesięczny plan publikacji
```

## 🔄 Repurposing Flow

```
BLOG POST (2000 słów)
    ├── 5 LinkedIn posts
    ├── 10 Twitter threads
    ├── 15 Instagram posts
    ├── 3 Newsletters
    └── 5 YouTube shorts

= 38 content pieces z 1 artykułu
```

## 💡 Użycie

### Komenda: "Repurpose [content]"
Wklej dowolny content → otrzymujesz wersje na 5 platform

### Komenda: "Content Waterfall [temat]"
Podaj temat → pełna strategia od bloga do social media

### Komenda: "Platform Switch [content] → [platforma]"
Przekształć istniejący post na inną platformę

## 🎯 Features

- ✅ Szablony dla LinkedIn, Twitter, Instagram, Blog
- ✅ Matryca przekształceń między platformami
- ✅ Bank pomysłów i kalendarz contentu
- ✅ Platform personality switch
- ✅ Content waterfall workflow

## 📊 Content Mix (70-20-10)

- 70% Edukacyjny (tips, tutorials, insights)
- 20% Personal (stories, behind the scenes)
- 10% Promocyjny (produkty, usługi)

## 🛠️ Tech Stack

- Markdown dla wszystkich szablonów
- Git dla version control
- AI agents (Claude, ChatGPT) dla generowania contentu
